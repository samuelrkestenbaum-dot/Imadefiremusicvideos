### 4. Techniques CANONIZED — `when-it-rains/PRODUCTION_PLAYBOOK.md`
The copy-paste bible for all remaining sections:
- **Spec-first staging** (template: `CAFE_SCENE_SPEC.md`) — locked room
  geometry, motivated blocking, reflection physics, on paper BEFORE generation.
- **Body-state law** — his body exists in **ONE take per setup**; inserts
  contain no part of him, so posture/hands can never mismatch.
- **Measured cuts** — media_import the take → `video_analysis` timestamps →
  exact in-points; never eyeball.
- **POV insert grammar** — "the camera IS his eyes…".
- **Environment-mirroring for reflections** — mirror the room/window/lights
  with her inside; a lone floating figure never reads as a reflection.
- **Surgical nano edits** (nano_banana_2, source still as only media) — "Edit
  this exact image with ONE change only… keep everything else identical."
  Proven for ring removal, text removal, figure removal (empty plates).
- **True ffmpeg composites** — empty-plate still + subject clip overlaid at
  `GHOST_OPACITY` (0.40 ghostly – 0.65 present), `setpts` on both layers.
- **wan2_7 lip-sync requires IMPORTED media** (media_import_url'd ids), NOT
  generation job ids — this **closes P-017's open mechanism question: PROVEN**.
- **Vocal relay** — slice from song.mp3 → commit to
  `when-it-rains/audio_relay/` → push → `raw.githubusercontent.com/<owner>/
  <repo>/<sha>/<path>` → `media_import_url`.
- **CI delivery** — `.github/workflows/render-chorus.yml` (input
  `script=<name>.sh`) renders on a connected runner, commits the mp4 to the
  branch → `git pull` → review in chat. (This retires the old "cannot render
  in-session" boundary as the delivery blocker.)

### 5. Character bible — HARD RULES (in every prompt with a person)
- **HIM:** buzz cut, **FULL hairline** (never "receding"/bald), reddish

- **HER = his ex:** pale skin, long dark wavy hair; appears **obliquely only**
  — reflections, glass, water, edge of frame. Never literal.
- **NO text in any frame** — always append "Absolutely NO text, NO signage,
