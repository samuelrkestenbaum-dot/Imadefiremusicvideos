## P-018 — Regenerate bed setup (intro v5)

**User feedback on intro_v4:** the nightstand insert was a **different
bedroom** (sunny, wrong sheets), and the bed had to become a **DOUBLE bed** so
the "her untouched side" beat works.

**Root cause (named, and fixed as process):** the insert had been generated
from a **fresh text prompt** instead of **derived from the scene master**; and
the sandbox **cannot see CDN images**, so assets were being used blind.

**Built — the CI review-fetch path ("sandbox eyes"):**
- `when-it-rains/scripts/fetch_review.sh` + a commit-step change in
  `.github/workflows/render-chorus.yml` (`eabfcd4`, extended `976f4bc`):
  CI downloads the assets listed in `when-it-rains/review_urls.txt` into
  `when-it-rains/review/` — **videos get 2fps frame PNGs** — so the sandbox can
  inspect every asset with Read **before spending or shipping**. This is the
  new standing QC instrument for all media packets.

**New assets — ALL derived from the user-approved soul_2 bed master
(job `2d080b77`):**
- **Bed take:** kling 10s, job **`eea03072`** — beats measured from the fetched
  frames: still 0–6s, head-turn 6.5–7.5s, rise 8.5–10s.
- **Her-half tight insert:** nano derivation chain **`9924df64` → `f64ef24d`**
  → kling 5s, job **`8bd72a9d`**.
- **QC catch on record:** the first derivation attempt (`9924df64`) was caught
  in frame QC showing the **WHOLE bed empty** (a continuity bug — her side must
  read untouched, not the bed abandoned) and was **re-derived tighter** —
  the review-fetch path paying for itself on its first outing.

**Output:** `when-it-rains/scripts/render_intro_v5.sh` → `intro_v5.mp4`
(CI-rendered, committed, delivered). **User verdict:** approved with
"Looks great except [opening shot mismatch]" → opened P-019.
